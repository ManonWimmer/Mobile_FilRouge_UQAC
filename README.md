# Mobile_FilRouge_UQAC

Notre application devait à la base être un réveil social, avvec gestion de groupes et paris sur des défis sportifs des membres (pas, temps d'activité, temps de sommeil...).

Actuellement, nous avons des réveils par groupe où des membres peuvent s'inscrire. Une fois le réveil sonné, un nombre de pas est à effectuer et vérifié via Health Connect. Si le défi est réussi, le membre gagne des points pour son classement du groupe !
